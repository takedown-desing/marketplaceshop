## Сборка на React

Актуальная версия лендинга — в `web/`: React 18 + TypeScript + Vite + Tailwind.
Фон первого экрана собран на пакете `shaders` (Swirl, ChromaFlow, FlutedGlass,
FilmGrain), иконки — `lucide-react`.

```bash
cd web
npm install
npm run dev        # разработка
npm run build      # прод-сборка в web/dist
npm run typecheck  # проверка типов
```

Движок шейдеров грузится отдельным чанком: основной бандл 197 КБ (62 КБ gzip),
шейдеры 2,5 МБ подтягиваются после первого экрана. Если браузер не тянет WebGL,
показывается статичный градиент — первый экран пустым не остаётся.

| Файл | Что это |
|---|---|
| `web/src/content.ts` | весь текст лендинга — правки вносятся здесь |
| `web/src/ui.tsx` | общие примитивы: контейнер, номерные плашки, кнопки с прокруткой подписи |
| `web/src/sections/*` | по файлу на секцию, порядок задан в `web/src/App.tsx` |
| `web/public/cases/` | превью кейсов |

Кликабельный прототип со всеми 18 блоками: <https://claude.ai/code/artifact/36e88cf6-98a7-4b7e-a17b-01de7adbd9d5>

Работают калькулятор потерь на комиссии, квиз на 6 шагов, аккордеон FAQ,
плавающая кнопка и поп-ап на уход со страницы. Формы показывают состояние
«отправлено» локально и никуда не отправляют — это прототип.

| Файл | Что это |
|---|---|
| `src/index.src.html` | исходник: разметка, стили, скрипты, плейсхолдеры `{{IMG_*}}` |
| `index.html` | собранная самостоятельная страница — открыть в браузере |
| `src/index.html` | та же сборка без `<head>` — для публикации артефактом |
| `assets/*.jpg` | превью кейсов, встраиваются в сборку как data-URI |
| `build.py` | сборка: `python3 build.py` |

Правки вносим в `src/index.src.html`, потом `python3 build.py`.

## Структура

18 блоков, 7 точек захвата. Полная раскладка — в проектном документе (вне репозитория).

## Документы

Аналитика спроса, разбор конкурентов и структура лендинга лежат **вне репозитория** —
он публичный, чтобы работал GitHub Pages, а там цены конкурентов, наша логика по марже
и список блокеров. Файлы `01-ANALYSIS.md`, `02-SEO-PROJECT.md` и `00-BRIEF.html`
хранятся локально в папке проекта и продублированы приватным артефактом.

## Стек

Статика HTML/CSS/JS, хостинг Cloudflare Pages. Формы — в Telegram-бот и на почту,
антиспам Turnstile. Аналитика — Яндекс.Метрика с целью на каждую из 7 форм.

## Что выяснилось при сборке

Из старого портфолио живёт только `tecona.ru`. Домены `kopaesh.ru`, `kludistore.ru`,
`upaksoyuz.ru`, `slesles.ru`, `rusfermer.ru`, `bio-ran.ru`, `agucci.ru`, `diamond-pro.ru`
не отвечают, а `lavka-cvetov.ru` припаркован и выставлен на продажу. В прототипе ссылка
стоит только на Tecona — на боевом лендинге ссылки на мёртвые сайты убьют доверие.
Нужны свежие кейсы или скриншоты из архива.
